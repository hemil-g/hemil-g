## 🏠 My Homelab

I believe a homelab is one of the best environments for developing practical engineering skills.

I maintain a virtualized infrastructure built around **Proxmox VE**, with FortiGate providing network security and an Ubuntu environment hosting containerized applications.

Some of the technologies and services in my environment:

| Technology | Implementation |
|:---|:---|
| Proxmox VE | Virtualization and LXC management |
| FortiGate Fortiswitch FortiAP | Firewall and network security |
| Ubuntu Server | Linux infrastructure |
| Windows Server | User management |
| Radius LDAP SAML ZTNA | IAM and Auth Infrastructure |
| Docker Compose & Kubernetes | Containerized application deployment |
| Nextcloud | Self-hosted cloud storage |
| PostgreSQL | Database services |
| Redis | Caching and application infrastructure |
| Apache Guacamole | Browser-based remote administration |

### Homelab Focus Areas

- Network architecture and VLAN segmentation.
- Virtual machines, containers, and resource management.
- Linux administration and troubleshooting.
- Docker-based application deployments.
- Storage management and self-hosted services.
- Infrastructure security and remote access.
- Automation and infrastructure improvements.
